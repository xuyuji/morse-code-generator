# 视觉参考与三个首页方向

调研日期：2026-10-13。暂用品牌名 Signal Desk，未完成域名、商标或命名验证。本文是设计建议，不是已验证的转化结论。

## 调研方法与边界

实际访问了 Radix Themes、IBM Carbon、GOV.UK Design System 的官方文档，以及 Cryptii、MorseCode.World、Google Morse Typing Trainer 的产品页。官方设计系统采用网页正文阅读；三个产品另外通过 Codex 内置浏览器查看了实际桌面首屏截图与可访问性树。没有实测这些竞品的手机布局、播放效果、转化率或网络请求，因此不把文档中出现的功能写成已通过操作验证，也不由截图推断它们的移动端表现。

用户新增约束：**移动端优先，接近原生 App 的操作体验**。下面三案都先定义手机结构，桌面布局只是扩展，不把桌面仪表盘直接缩小。

## 三案共同的手机交互基线

- 页面主流程为“输入 → 看结果 → 复制或播放”，打开即能用；不放大型营销横幅、登录入口或新手弹窗阻挡输入。
- 先按 390px 宽手机设计，并验证 360px、430px、横屏及桌面。导航保持一行品牌与菜单；未来工具较多时再考虑全站工具搜索，不预填一排尚未发布的入口。
- 默认显示文本输入与结果摘要，输入框约 120–160px 起步；结果较长时允许展开。模式切换不清空用户内容；不会因更新结果抢走输入焦点。
- 核心按钮触控区域以 44–48px 为项目目标；图标同时配文字。WCAG 2.2 AA 的目标尺寸规则为 24×24 CSS px 或满足规定例外，44px 是我们更宽裕的产品目标，不混同为 AA 强制要求。[W3C 目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)
- 底部操作区保留安全区；软键盘弹出时要可收起或进入正常文档流，不能盖住输入光标、错误提示和结果。不要靠写死 `100vh` 制造被浏览器工具栏截断的页面。
- 播放由用户主动触发，播放中同一位置提供停止；仅声音输出必须有文字等价结果。复制后的反馈贴近按钮且不跳页。
- 正文通常 16–18px；普通文字对比度目标至少 4.5:1，大字至少 3:1；颜色之外使用文字/图标表达错误。焦点可见，结果区使用克制的状态通知，避免每个按键都让读屏重复朗读整段译文。[W3C 文字对比](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)
- 点划展示可用等宽字体，但实际可复制值统一为 ASCII `.`、`-`、字母间空格与单词间 `/`。视觉装饰不能改变复制内容。

## A：Clear Utility / 清晰工具台（推荐作为全站主方向）

**感受：** 安静、明确、立即可用。参考 Radix 的组件秩序、GOV.UK 的任务清晰度、Cryptii 的输入输出关系；不复制任一站点皮肤。

**手机结构：** 紧凑品牌栏 → H1 与一句解释 → Text / Morse 方向切换 → 白色输入区 → 带 Copy 的结果区 → Play 与 WAV download 操作 → 折叠 Audio settings → 示例词条 → 速查和相关工具。两块编辑区组成一个工具整体，不再外套多层卡片。桌面宽度足够时输入输出并排，参数仍为次级区域。

**视觉建议（自拟 token）：** 背景 `#F5F7F9`，面板 `#FFFFFF`，正文 `#17212B`，辅助文字 `#52606D`，主操作 `#12615A`，浅强调 `#E7F3EF`；输入框边界要比装饰分隔线清楚。系统无衬线字体配系统等宽字体；圆角 10–14px；以间距和细边框分组，少量阴影。以上是候选值，仍须按最终控件组合校验对比度。

**原生感：** 分段选择器、触控友好的复制/播放、操作反馈不改变布局，键盘展开时只保留必要动作。高级设置可用内联折叠，首发不必为一个滑杆构建复杂抽屉。

**适用性：** 从 Morse 扩展到 Base64、Binary、URL 时无需换品牌语言；适合搜索进入后快速完成任务。风险是过于普通，品牌识别应来自点划符号、小范围绿色和一致排版，而不是额外插图。

## B：Signal Console / 信号控制台

**感受：** 精确、有控制感。借鉴 Carbon 深色层级和 MorseCode.World 参数的领域价值。

**手机结构：** 窄顶栏与工具身份 → 单个全宽输入编辑区 → “OUTPUT” 结果显示区 → 播放/停止主操作与实际播放进度 → 一行 WPM / Hz / Volume 参数摘要 → 可展开参数底板 → 可听字母条。底板关闭时页面是一个紧凑控制台；桌面才把参数移至右侧。输入和结果不是 A 案的两块对称卡片，而是有明确纵向信号流程的工作区。

**视觉建议（自拟 token）：** 底色 `#101820`，工作层 `#1B2833`，输入层 `#243442`，主文字 `#F0F5F8`，辅助文字 `#B3C2CC`，强调青色 `#78E0CE`，提示琥珀色 `#F7CB73`；圆角 4–8px；正文系统无衬线，数字与点划使用等宽字体。边线承担区域划分，不使用发光大阴影。

**原生感：** 控件大而直接；滑杆旁有可输入数字与单位；参数底板须支持关闭、焦点回到触发器和键盘操作。信号进度必须对应实际音频状态，无输入时用静态示例或空状态，不伪装正在测量。

**适用性：** 音频、Practice、技术编码工具表现突出。风险是让学生和第一次使用者以为必须懂参数；因此默认参数可直接用，专业区默认收起。暗色只是方案定位，若采纳为全站风格仍应规划浅色与系统主题支持。

## C：Field Notes / 纸上电报码

**感受：** 温暖、好懂、愿意探索。纸张与编辑式排版是本项目的原创组合；GOV.UK 提供可读性参照，Google Trainer 提供学习引导的参照，二者都不是现成纸质模板。

**手机结构：** 简洁刊头 → H1 → 编号 01 “Write your message” 与输入 → 编号 02 “Read the signal” 与点划结果 → 一张横向 Listen / Copy 操作卡 → 可折叠“Why spaces matter”小提示 → 字母速查索引。步骤连续显示并即时响应，不变成必须逐步点 Next 的向导。桌面保持窄主阅读列，右侧出现便签式参考表。

**视觉建议（自拟 token）：** 纸色 `#F7F2E7`，内容区 `#FFFCF5`，墨色 `#2A332B`，辅助文字 `#5F6258`，主操作深绿 `#315344`，少量赭色 `#99552D`。标题 Georgia/系统衬线，正文系统无衬线，结果系统等宽；用细规则线、编号与留白建立结构；不加载噪点纹理图片，也不让文字压在装饰纸纹上。

**原生感：** 像轻量笔记 App：输入与结果连续、操作卡触手可及，长知识内容按需展开。可在练习页以字母卡延续视觉，但首页不加入成绩、签到或课程进度干扰即时转换。

**适用性：** 学生、教师、谜题与手作场景容易理解；Alphabet / Chart / Tattoo 页可形成辨识度。风险是 Base64 等开发者工具显得偏教学；需保持工具动作简洁，装饰仅用于标题与分隔，不用于表单本体。

## 选择依据与原型范围

| 比较项 | A 清晰工具台 | B 信号控制台 | C 纸上电报码 |
| --- | --- | --- | --- |
| 手机结构 | 一体化双区，平级可比 | 纵向信号流程，参数底板 | 连续编号步骤，学习小提示 |
| 视觉中心 | 输入与结果 | 结果与播放状态 | 文字与点划之间的关系 |
| 桌面扩展 | 双栏编辑 | 主工作区＋右侧参数 | 主阅读列＋参考便签 |
| 最适合的任务 | 快速转换、复制 | 听音、调参、持续练习 | 理解、查表、教学与创作 |
| 风险 | 缺少辨识度 | 专业感增加心理门槛 | 说明和装饰挤压工具 |

推荐先选 A 作为全站基线：覆盖普通搜索用户与未来开发者工具的跨度更自然。B、C 保留为有真实差异的候选，不只替换颜色。这个推荐是根据产品范围的设计判断，后续用首次完成转换时间、误操作、参数发现率与移动端任务完成情况验证，不能宣称已有数据支持。

三份原型统一使用 **Morse Code Translator 首页**、同一段 `HELLO WORLD` 示例、相同核心功能与真实输出。都应支持编辑、方向切换、复制、播放/停止、参数和下载；若某项仍是展示，明确写出。主预览先展示手机视口，再展示桌面扩展。以 360px / 390px / 430px 验证无横向溢出，另查软键盘遮挡、较长输入、未知字符、空结果和连续播放停止。
