日期：2026-10-13。状态：已实施的产品/技术基线；用户已明确移动优先，并于2026-10-13确认视觉A。

1. 从Morse核心任务开始，逐步扩展编码工具；不按25个关键词同时制造25个薄页面。
2. 手机先行；“接近原生”指任务流、触控、反馈和键盘行为，原生壳/PWA安装不是首发前提。
3. 通用转换变体先归首页；独立页面须有不同任务或交付物。路由清单以 `spec/product-plan.md` 为准。
4. 输入默认本地处理；普通转换不依赖AI/API。复杂解码、破解和盲文需要单独规范与样本验证。
5. SEO以当前官方依据和真实产品质量为准，取消FAQ富结果、外链配额、精确标题等机械验收。
6. 正式MVP采用Astro+TypeScript静态页面与小型客户端模块；依赖已核对并锁定，研究与历史原型不进入构建产物。
