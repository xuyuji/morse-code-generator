# 移动优先设计方案

2026-10-13。用户已确认采用 **A「清晰工具台」**；正式域名为dotsdashes.com，品牌文字暂按DotsDashes实施；Signal Desk仅保留于历史原型。参考来源、竞品观察与限制见 [design-references](../docs/research/design-references.md)。

## 选择入口

启动 `npm run prototype`，打开 [三案并排对比](http://127.0.0.1:4173/compare.html)。单独体验：[A](http://127.0.0.1:4173/?variant=A)、[B](http://127.0.0.1:4173/?variant=B)、[C](http://127.0.0.1:4173/?variant=C)。默认手机宽度，桌面页面左侧可切换桌面布局；浏览器刷新恢复手机评审模式。原型切换保留当前输入、方向和参数，停止旧播放。

| 方案 | 布局 | 视觉规则 | 最适合 | 代价 |
|---|---|---|---|---|
| A 清晰工具台（已选定） | 一体输入/结果，分段方向，复制/播放并列 | 冷白底、深绿动作、浅绿结果；系统无衬线；14px卡片圆角 | 全站统一，从学生延伸至开发者 | 辨识度靠一致细节与点划标志 |
| B 信号控制台 | 输入→信号显示→播放；独立参数区 | 深蓝灰底、薄荷色信号；数字等宽；小圆角和清晰分隔 | 音频、练习、开发调试 | 专业感可能让新手犹豫，默认参数须直接可用 |
| C 纸上电报码 | 01输入→02读码，连续步骤；纸条结果 | 暖纸、墨绿、少量赭色；衬线标题+无衬线控件；规则线 | 课堂、解谜、手作与查表 | 要防止解释过多拖慢即时任务 |

三案功能一致，差异不仅是换色。A借鉴Radix的控件秩序、Cryptii的输入输出关系；B借鉴Carbon深色层级和MCW声音参数；C用原创纸张排版结合GOV.UK阅读顺序、Google Morse学习产品的友好引导。未复制第三方图像或字体资产。

## 跨工具视觉规范

- 页面默认英文，同时提供 `/zh/` 简体中文，中文按本地习惯改写；历史评审框架为中文。主站品牌应支持非Morse工具，避免把全部品牌资产绑定电报机。点划是轻量识别元素，不做满屏主题装饰。
- 全站共享语义 token：background / surface / text / muted / border / action / result / error / focus。采用A的冷白、深绿与浅绿结果区；正式组件实现时固定token并验证对比度，B/C保留为历史参考。
- 4px基础间距：8/12/16/24/32；手机左右20px，桌面最大正文约1080px；正文说明最大行宽约65字符。
- 正式正文16px起，辅助说明12–14px，工具输入至少16px以避免iOS聚焦放大，主标题28–34px；代码输出20–24px等宽、可选择、可换行。原型部分微标签10–11px仅用于评审层级，正式版需提高并实机验证。
- 主要点击目标44–48px；图标有文字或accessible name；状态用文本与颜色共同表达；不以自动闪光或持续动效作为默认反馈。
- 操作最多一主一次：转换工具是Copy/Play或Copy/Download；参考页是Hear/Print；练习页是Submit/Replay；创作页是Preview/Export。按任务变化，不硬套播放键。

## 四种页面骨架

| 类型 | 手机首屏 | 第二层 | 桌面扩展 |
|---|---|---|---|
| 转换（首页/Binary/Base64/URL） | 方向→输入→结果摘要→主要动作 | 编码选项、错误解释、示例 | 输入与输出并排 |
| 查表（Alphabet/Numbers/NATO/Chart） | 搜索/筛选→可读字符表→试听或下载 | 打印选项、标准、短解释 | 更密集网格+旁侧说明 |
| 练习（Practice） | 播放→回答→即时反馈 | 本轮错字、再练、难度 | 练习主区+本轮统计 |
| 创作/信号（Tattoo/Generator/Semaphore） | 内容→可视预览→导出或播放 | 精度/样式/尺寸/视角 | 预览主区+参数侧栏 |

## 接近原生 App 的行为规格

紧凑顶栏、明确当前任务、分段控件、即时反馈、拇指可及动作，比伪造手机状态栏更重要。按钮加载时保持宽度；模式切换不丢内容；操作完成不跳页；菜单不覆盖无法恢复的编辑状态。

键盘打开时：输入、最近结果与错误可滚动到可见区域，折叠非必要固定栏。使用动态视口、安全区padding；不能用fixed底栏遮挡浏览器工具栏或光标。原型评审切换栏不属于正式产品。

设置：少量参数用内联折叠；复杂设置再用底部sheet，支持关闭、焦点约束和返回焦点。滑杆同时显示单位；生产版增加数字输入以支持精确调节。

权限：只有用户请求录音才触发麦克风权限；拒绝后可用文件或文字输入。Clipboard失败提供可选中文本。下载按设备支持降级为保存/分享指引；不承诺iOS原生下载路径。音频仅用户触发，停止/切换/页面隐藏取消播放。

离线与安装：属于后续增强，先把首次访问和低网速核心体验做好；若做PWA，要有缓存升级、错误恢复和版本提示，不默认弹安装提示。

## 交互原型边界

已实现：A–Z/0–9与常用标点、点划输入归一化、非法符号标记、300字符上限、方向切换、示例、复制及失败反馈、5–40WPM/300–1000Hz、Web Audio试听/停止、WAV生成（2分钟上限）、字母试听、可展开完整字母数字表。感叹号属扩展映射，生产版需分组标注。SOS示例是普通文字转换，连续求救prosign尚未实现，页面说明已区分。

原型不是正式算法或PWA；尚未做麦克风/文件解码、Farnsworth、训练、纹身导出、统计接入、SEO生产配置。截图与检查记录见 [验证记录](../docs/research/validation.md)。
